# POPTUNG

A simple clicking game where you can click or tap to increase your score and discover fun surprises along the way! 🐱🪵

This is one of my first projects, made for fun while I'm still learning. Hope you enjoy it!

## ✨ Features

- Click or tap to increase your score.
- Fun animations and sound effects.
- Special surprises at 30 and 67 clicks.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
